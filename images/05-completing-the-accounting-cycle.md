# Figure briefs — Chapter 5: Completing the Accounting Cycle

## Figure 5.1 (optional): The nine-step accounting cycle

**Placement:** §5.4.

**Description:** A circular flow diagram showing all nine steps. Steps 1-4 (continuous through period) on one arc; steps 5-9 (period-end) on the other arc. Loop arrow back to step 1 emphasizing the cycle.

**Pedagogical purpose:** Locates this chapter (steps 8-9) within the larger cycle that began in Chapter 3.

**Style notes:** Circular flow chart; numbered steps; visual distinction between continuous and period-end steps.

## Figure 5.2 (optional): Closing entries flow

**Placement:** §5.3.

**Description:** Four-arrow diagram showing the four closing entries. Arrow 1: Revenues → Income Summary. Arrow 2: Expenses → Income Summary. Arrow 3: Income Summary → Owner's Capital (or Retained Earnings). Arrow 4: Owner's Withdrawals (or Dividends) → Owner's Capital (or Retained Earnings).

**Pedagogical purpose:** Make the four-step closing process visual.

**Style notes:** Numbered arrows. Use color or shading to distinguish the temporary accounts (zeroed out) from the permanent equity destination.

## Figure 5.3 (optional): Classified balance sheet template

**Placement:** §5.5.

**Description:** A blank template balance sheet with all the major classifications labeled — Current Assets, Long-term Investments, PP&E, Intangible Assets on the asset side; Current Liabilities, Long-term Liabilities, Equity on the liabilities-and-equity side. Sample line items as illustrative entries.

**Pedagogical purpose:** Reference template students can use as a starting point for assignments.

**Style notes:** Standard balance-sheet format; clean tabular.
